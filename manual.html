AccessPoint – Documentação Técnica & Manual

Plataforma completa para gerenciamento de acesso físico em escolas, utilizando cartões RFID e módulos ESP32.
Funcionalidades: cadastro de cartões, permissões granulares por porta, logs em tempo real, interface responsiva e API REST para hardware.

Totalmente funcional – pronto para implementação.

🚀 Instalação & Configuração

  1. XAMPP – inicie Apache e MySQL.
  2. Baixar projeto – copie a pasta access_control para htdocs.
  3. Banco de dados – crie um schema access_control no phpMyAdmin e importe database.sql.
  4. Credenciais – configure includes/db.php (padrão: root / sem senha).
  5. Usuários iniciais – acesse fix_users.php para gerar admin/admin123 e direcao/direcao123.
  6. Acesse → http://localhost/access_control/login.php
O sistema já vem com cartões e dispositivos de exemplo para testes rápidos.

🏗️ Arquitetura do Sistema

Front-end
HTML5, CSS3 (Flex/Grid), JavaScript (Fetch API, modais). Integração com REST via AJAX.
Back-end
PHP 7.4+ com prepared statements, controle de sessão, password_hash().
Banco de dados
MySQL – tabelas otimizadas com chaves estrangeiras e índices.
Hardware
ESP32 + leitor RFID (MFRC522) – comunicação via HTTP POST com JSON.
FLUXO DE COMUNICAÇÃO:

[Cartão RFID] → ESP32 (leitura UID) → POST /api/verify_card.php → verificação no banco → resposta {open_door} → ESP32 aciona trava → log registrado.

👥 Perfis e Controle de Acesso

PerfilPermissõesAcesso a usuários
👑 AdministradorTotal: CRUD de cartões, dispositivos, usuários, logs, configurações.✅ Sim

Todas as páginas sensíveis possuem verificação via requireAdmin(). As senhas são armazenadas com bcrypt (hash seguro).

📡 Integração Técnica – ESP32

Endpoint: POST http://IP_DO_SERVIDOR/access_control/api/verify_card.php
Headers: Content-Type: application/json

{
  "card_uid": "12345678",
  "device_id": 2
}

Resposta (acesso liberado):

{
  "success": true,
  "message": "Acesso liberado para Laboratório de Informática",
  "open_door": true
}

Resposta (negado):

{
  "success": false,
  "message": "Cartão bloqueado ou sem permissão.",
  "open_door": false
}

🔌 Código de exemplo para ESP32 (Arduino IDE)

#include <WiFi.h>
#include <HTTPClient.h>

const char* server = "http://192.168.0.100/access_control/api/verify_card.php";

void loop() {
  if (rfid_presente) {
    HTTPClient http;
    http.begin(server);
    http.addHeader("Content-Type", "application/json");
    String payload = "{\"card_uid\":\"" + uidString + "\",\"device_id\":1}";
    int httpCode = http.POST(payload);
    if (httpCode == 200) {
      String resposta = http.getString();
      if (resposta.indexOf("\"open_door\":true") != -1) {
        digitalWrite(RELAY_PIN, HIGH);
        delay(3000);
        digitalWrite(RELAY_PIN, LOW);
      }
    }
    http.end();
  }
}

💻 Estrutura do Código e Boas Práticas

Segurança – todas as consultas utilizam prepared statements para evitar SQL Injection.

$stmt = $conn->prepare("INSERT INTO cards (card_uid, holder_name) VALUES (?, ?)");
$stmt->bind_param("ss", $uid, $nome);
$stmt->execute();

Controle de sessão em includes/auth.php:

session_start();
function isLoggedIn() { return isset($_SESSION['user_id']); }
function requireAdmin() { if ($_SESSION['user_role'] != 'admin') die("Acesso negado"); }

API central – o arquivo api/verify_card.php processa as requisições do ESP32 e registra os logs automaticamente.

✅ Código comentado e organizado – fácil de manter e expandir.

❓ Perguntas Frequentes (FAQ)

❓ O sistema funciona apenas com XAMPP?
Pode ser usado em qualquer servidor Apache + PHP + MySQL (WAMP, LAMP, Docker).
❓ Como um cartão é liberado em determinada porta?
No cadastro do cartão, marque o(s) dispositivo(s) na seção "Permissões de Acesso".
❓ O ESP32 pode estar em outra rede?
Sim, desde que o servidor tenha IP acessível e as portas estejam liberadas.
❓ O simulador substitui o hardware?
Para testes de lógica de permissão, sim. Para a apresentação, comprova que a API responde corretamente.
